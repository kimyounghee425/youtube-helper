# Browser Companion

정보 전달용 영상(컨퍼런스 발표, 강의, 뉴스)을 보다가 멈추고,
**방금 나온 내용을 기준으로** 바로 질문하고 토의하는 Chrome 확장.
`interview-helper`에서 확장 기본 틀만 가져온 독립 레포다.

## 해결하려는 문제

FEConf 같은 발표 영상을 그냥 흘려들으면 이해가 안 된다.
그래서 영상을 멈추고, 자막이나 내용을 ChatGPT에 옮겨 적고, 질문하고, 다시 재생한다.
이 왕복이 번거로워서 질문을 건너뛰고, 결국 영상을 대충 보게 된다.

이 확장은 그 왕복을 없앤다. 영상을 멈추고 사이드패널에 묻기만 하면 된다.

첫 사용자는 나 자신이다. 먼저 내가 영상의 막힌 부분을 이해하고 학습을 이어갈 수 있게 만든다.
다른 사용자에게 배포하거나 미팅 도우미·에이전트로 확장하는 일은 이 문제가 해결된 뒤 검토한다.

- "방금 뭐라고 한 거야?" → 직전 구간의 자막을 근거로 설명한다.
- "저 용어 뭐야?" → 발표 맥락 안에서 풀어준다.
- 내일 같은 영상을 열면 어제 어디까지 봤고 무엇을 물었는지 이어진다.

## 하지 않는 것

- 영상 전체 요약을 중심으로 한 기능.
- 범용 "현재 페이지 보고 답하기".
- 미팅·인터뷰 실시간 보조와 자동 행동 에이전트. 개인 영상 학습 문제가 풀린 뒤에 검토한다.
- 면접 기능, 결제, 계정 시스템. 쓸 사람이 생긴 뒤에 붙인다.

## 사용 흐름

1. 유튜브에서 발표 영상을 재생하면서 사이드패널을 열어둔다.
2. 이해가 안 되는 지점에서 영상을 멈추고 질문한다. 자막을 복사하거나 상황을 설명할 필요가 없다.
3. 답변은 방금 지나간 구간을 근거로 나온다. 이어서 물어보거나 다시 재생한다.
4. 다음에 같은 영상을 열면 지난 질문과 멈췄던 지점이 그대로 있다.

질문에는 질문 시점의 재생 시간과 관련 자막 구간을 연결한다.
자막에 근거한 설명과 AI의 보충 설명을 구분하고, 맥락이 부족하면 추측 대신 부족한 부분을 알린다.

## 구현 전제와 제약

- 확장이 유튜브 자막과 현재 재생 시간을 읽어 질문·이전 대화와 함께 OpenAI API에 보낸다.
- 첫 버전은 자막이 있는 유튜브 영상만 지원한다. STT는 자막 없는 영상이나 미팅 모드가 필요해질 때 붙인다.
- 화면·슬라이드의 시각 정보는 첫 버전에서 읽지 않는다. 자막만으로 이해할 수 없는 내용은 한계로 표시한다.
- 자막 등 페이지 정보는 사용자가 질문하거나 명시적으로 요청할 때만 수집·전송한다.
- 유튜브 자막 추출은 비공식 방식이라 유튜브가 바뀌면 깨질 수 있다.
- 초기에는 사용자가 자기 OpenAI API 키를 넣고 호출 비용을 부담한다. 키 보관 방식은 구현 전에 정하며 키를 저장소에 커밋하지 않는다.
- 대화와 재생 위치는 영상별로 로컬에 저장한다. 기존 ChatGPT 대화·프로젝트와의 동기화는 범위에 넣지 않는다.

## 검증 계획

1. 실제로 공부할 FEConf 등 영상 하나에서 막히는 지점과 평소 질문 방식을 기록한다.
2. 최소 버전으로 같은 작업을 해본다. 질문 시점의 재생 시간·자막을 바탕으로 문답하고, 영상별로 대화와 위치를 로컬에 저장한다.
3. 영상 3개를 공부하며 아래 기준으로 내 불편이 줄었는지 확인한다. 기존 도구와의 기능 차이는 확인 전까지 가설로 둔다.

- 자막을 복사하거나 다른 탭으로 이동하지 않고 질문할 수 있는가?
- 답변이 영상 전체가 아니라 내가 막힌 지점을 설명하는가?
- 후속 질문으로 이해한 뒤 영상 학습을 이어갈 수 있는가?
- 다음 날 같은 영상에서 지난 문답과 재생 위치를 찾아 이어갈 수 있는가?

질문 횟수만으로 성공을 판단하지 않는다. 내가 반복해서 쓰게 된 이후에 다른 사용자의 수요를 검증한다.

## 현재 구현

확장 아이콘을 누르면 React 사이드패널의 시작 화면이 열린다.
자막 수집, AI 호출, 대화 저장은 아직 구현하지 않았다.
현재 권한은 `sidePanel` 하나이며 페이지나 오디오를 읽지 않는다.

## 실행

Node.js 22 이상과 pnpm 10.12.2를 사용한다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

1. `chrome://extensions`에서 개발자 모드를 켠다.
2. **압축해제된 확장 프로그램 로드**에서 이 레포의 `dist/`를 선택한다.
3. 확장 아이콘을 누르면 사이드패널이 열린다.

코드 변경 후에는 확장 관리 화면에서 새로고침하고 패널을 다시 연다.

```sh
pnpm build          # 타입 검사와 배포용 빌드
pnpm test           # 빌드 결과의 진입점과 사이드패널 설정/오류 처리 확인
pnpm format:check
```

## 가져온 것과 제외한 것

- 재사용: React·TypeScript·Vite 구성, React 진입점, 사이드패널 HTML과 기본 스타일.
- 수정: manifest의 이름과 권한, 패널 열기 동작, 시작 화면.
- 제외: 오디오 캡처, STT, 면접 전사와 질문 판정, 직군 프롬프트, 모의 질문,
  답변 파서, PDF 업로드, 면접 설정 화면, OpenAI SDK와 직접 API 키 입력 방식.
  STT와 API 키 입력은 위 계획에 따라 필요 시 다시 가져온다.
- 원본 Git 이력, 사용자 데이터, 환경 파일, 기존 빌드 산출물은 복사하지 않는다.
