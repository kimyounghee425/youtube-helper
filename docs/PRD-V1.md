# PRD V1: 영상 학습 PoC

> **영상에서 막히면 복붙 없이 질문하고 이해한 뒤 다시 본다.**

## 1. 검증할 것

- **사용자:** 컨퍼런스나 강의 또는 뉴스 영상을 보며 공부하는 나.
- **문제:** 영상을 멈추고 내용을 ChatGPT에 옮겨 설명하느라 학습 흐름이 끊긴다.
- **목표:** 유튜브 옆에서 현재 구간에 대해 질문하고 후속 문답으로 이해를 해결한다.
- **환경:** 개인용 Chrome 확장. 자막을 가져올 수 있는 유튜브 일반 영상.

## 2. 사용 흐름

1. 유튜브 영상에서 사이드패널을 연다. 해당 영상의 대화가 자동으로 표시된다. 키가 없으면 내 OpenAI API 키를 입력한다.
2. 영상을 보다가 막히면 직접 일시정지한다.
3. “방금 무슨 뜻이야?”라고 묻는다. 필요하면 이어서 질문한다.
4. 이해하면 영상을 다시 재생한다.
5. 다음에 같은 영상을 열어 지난 문답과 마지막 질문 지점부터 이어간다.

## 3. 제공할 기능

| 기능                | PoC에서 제공할 동작                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **API 키 입력**     | 키를 가려서 입력한다. 교체하거나 삭제할 수 있다. 본인 키로 호출하며 비용은 본인이 부담한다.                                                |
| **현재 구간 연결**  | 영상 진입 시 전체 자막을 자동으로 준비한다. 질문할 때 현재 재생 시간과 관련 자막을 연결한다.                                               |
| **질문과 토의**     | 현재 구간과 같은 영상의 이전 문답을 참고해 답한다. 용어를 풀어주고 쉬운 예시를 든다. 후속 질문도 지원한다.                                 |
| **영상별 이어하기** | 문답과 마지막 질문 시점을 로컬에 저장한다. 같은 영상에서 복원한다. 해당 시점으로 이동하거나 기록을 삭제할 수 있다.                         |
| **실패 안내**       | 자막이 없거나 추출에 실패한 경우를 구분한다. 키 오류와 한도 초과 및 통신 실패도 안내한다. 질문 초안을 유지하고 직접 재시도할 수 있게 한다. |

## 4. 초기 동작 기준

- **자막 수집:** 패널을 열지 않아도 영상 진입 시 선택한 언어의 전체 자막을 수집한다. 탭별로 임시 보관하며 영상 변경이나 탭 종료 시 비운다. 자막 본문은 화면에 표시하지 않는다.
- **질문 맥락:** 수집 범위와 AI에 전달할 범위는 구분한다. 고정된 2분 제한은 두지 않는다. 질문에 필요한 자막을 고르는 방식은 문답 구현 시 정한다.
- **답변:** 한국어로 핵심부터 짧게 설명한다. 영상 근거와 AI의 보충 설명을 구분한다. 맥락이 부족하면 부족한 정보를 알린다.
- **대화 전환:** 영상 ID별로 대화 하나를 유지한다. 패널을 열면 기존 대화를 자동으로 표시한다. 기록이 없으면 빈 대화로 시작한다. 패널이 열린 채 다른 영상으로 이동해도 해당 영상의 대화로 전환한다. 세션을 직접 만들거나 선택하는 과정은 없다. 마지막 질문 시점만 저장하며 전체 시청 이력을 추적하지 않는다.
- **키와 기록:** 키는 브라우저 세션 동안만 유지하고 재시작 후 다시 입력한다. 문답은 같은 브라우저에 보관하며 다른 영상과 섞지 않는다.
- **전송:** 사용자가 질문할 때만 필요한 자막과 질문 및 이전 문답을 OpenAI에 보낸다. 백그라운드 AI 호출이나 자동 재시도는 하지 않는다.

## 5. 이번에 제외

| 범주        | 제외 항목                                                |
| ----------- | -------------------------------------------------------- |
| 영상        | 자막 없는 영상과 실시간 방송. Shorts와 다른 영상 플랫폼. |
| 입력        | 음성 질문과 STT. 화면이나 슬라이드 또는 이미지 분석.     |
| 학습 도구   | 영상 전체 요약과 노트 편집. 퀴즈와 외부 검색.            |
| 서비스 확장 | 미팅 보조와 자동 행동 에이전트. 계정과 결제.             |
| 연동과 배포 | 기존 ChatGPT 기록 연동과 기기 간 동기화. 웹스토어 배포.  |

## 6. 완료 기준

자막을 가져올 수 있는 실제 학습 영상 **3개**로 직접 확인한다.

- [ ] 복붙이나 탭 이동 없이 현재 구간에 대해 질문할 수 있다.
- [ ] “더 쉽게 설명해줘” 같은 후속 질문이 앞선 문답에 연결된다.
- [ ] 답변을 통해 막힌 부분을 이해하고 영상 학습을 이어갈 수 있다.
- [ ] 처음 연 영상은 빈 대화로 시작한다. 다시 연 영상은 기존 문답이 자동으로 표시된다. 다른 영상으로 이동하면 대화도 전환된다. 저장된 마지막 질문 지점으로 이동할 수 있다.
- [ ] 자막이나 API 오류 시 원인과 다음 행동이 보인다. 질문은 사라지지 않는다.

**한계:** 자막 추출 가능 여부는 구현 검증이 필요하다. 자막에 없는 시각 정보와 자막 오류는 답변 품질을 제한한다.
