# TASK 02: 현재 영상 맥락으로 질문하기

## 배경과 목적

TASK 01에서 전체 자막을 준비했다. 이제 영상을 보다가 막힌 내용을 복붙 없이 질문할 수 있게 한다.
자막만으로는 현재 보고 있는 지점을 알 수 없고 슬라이드 설명도 놓칠 수 있다. 질문을 보낼 때 재생 시간과 현재 영상 프레임 한 장을 함께 가져온다.
실제 문답으로 학습 흐름이 편해지는지 확인하는 것이 목적이다.

## 할 일

1. 본인의 OpenAI API 키를 입력하고 교체하거나 삭제할 수 있게 한다. 키는 브라우저 세션 동안만 보관한다.
2. 질문 전송 시 현재 재생 시간과 영상 프레임 한 장을 수집한다. 재생 시간을 계속 추적하거나 프레임을 미리 쌓지 않는다.
3. 자막과 질문 시점 및 프레임을 참고해 GPT가 답하게 한다. 질문에 연결된 재생 시간을 표시한다.
4. 같은 영상의 이전 문답을 참고해 후속 질문에 답한다. 대화는 임시로 유지하며 다른 영상의 맥락과 섞지 않는다.
5. 한국어로 핵심부터 짧게 답한다. 영상 근거와 보충 설명을 구분하며 맥락이 부족하면 알린다.
6. 수집이나 API 요청 실패 시 원인과 다음 행동을 안내한다. 질문을 유지하고 수동 재시도를 제공한다.

## 동작 기준

텍스트와 이미지를 함께 처리하는 `gpt-5.4-mini`로 시작한다. 자막은 영상 시작부터 질문 시점에 걸친 발화까지 전달한다. 앞선 설명을 참고할 수 있도록 고정된 2분 제한은 두지 않는다.
대화는 현재 패널에서만 임시로 유지한다. 패널을 닫거나 다른 영상으로 이동하면 비운다.

## 제외

대화 영구 저장과 다음 날 이어하기는 TASK 03에서 다룬다. 과거 프레임 탐색과 STT 및 자동 행동 에이전트는 제외한다. 백엔드는 만들지 않는다.

## 확인

영상을 멈추고 “여기 이해가 안 돼”라고 물으면 해당 시점의 내용을 설명받고 후속 질문을 이어갈 수 있어야 한다.
실제 유튜브와 본인 키를 사용한 학습 확인은 사용자가 직접 한다. 에이전트는 로컬 테스트를 담당한다.
