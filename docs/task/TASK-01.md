# TASK 01: 유튜브 영상의 전체 자막 수집

## 배경과 목적

GPT가 영상 내용을 참고하려면 시간 정보가 있는 전체 자막이 필요하다.
사용자가 유튜브 영상에 들어오면 해당 자막을 자동으로 준비한다. 자막 본문을 사용자에게 보여줄 필요는 없다.

## 할 일

1. 영상 진입과 영상 변경을 감지해 선택한 언어의 전체 자막을 가져온다. 사이드패널이 닫혀 있어도 동작한다.
2. 자막은 해당 탭의 임시 데이터로 보관한다. 패널에는 영상 정보와 수집 상태만 표시한다.
3. 자막 없음과 추출 실패를 구분한다. 실패한 경우 다시 시도할 수 있게 한다.
4. 영상이 바뀌면 이전 데이터를 비운다. 늦게 도착한 이전 요청은 무시한다.

## 제외

2분 필터와 자막 본문 표시. AI 문답과 API 키 입력 및 대화 저장. 프레임 수집과 STT.

## 확인

실제 유튜브에서의 동작은 사용자가 직접 확인한다. 에이전트는 로컬 테스트를 담당한다.
